# AI Usage Disclosure

I used AI tools during the development of this project as a way to support my learning and improve efficiency.

The original version of this application was built using pure PHP. While working on this project, I used AI to help me port the frontend into Vue.js, especially when converting existing views into components and organizing the structure of the app.

I also used AI as a learning aid for technologies I was not fully familiar with, including:

- Pinia (state management)
- JWT authentication
- WebSockets for real-time features

In addition, I used AI when I got stuck on specific problems, such as debugging issues or resolving errors (for example, dealing with CORS issues between the frontend and backend).

I want to be clear that I did not blindly copy code. I tried to understand the suggestions, test them, and adapt them to fit my project. AI mainly helped me:

- understand concepts faster
- explore possible solutions
- unblock myself when I was stuck

All final decisions and implementations were made by me, and I take full responsibility for the code in this project.
